# Журнал изменений

Записи до 0.8.0 восстановлены по прежней документации проекта; у версий до 0.5 сведений не осталось.

## 0.8.0

Добавлено

- `devctl zip` — эволюционный архив workspace: вся история проекта и материалов вокруг него одним zip
  для чтения нейросетью. Одинаковые деревья файлов считаются одним состоянием, состояния описаны
  отличиями, посторонние материалы стоят в общей хронологии, объём подгоняется под бюджет
  (`--level brief|normal|full|max`, `--budget-kb`). См. [evolution-archive.md](evolution-archive.md).
- Тесты `tests/test_evolution_digest.py`: строят workspace настоящим `devctl start` и проверяют архив.

Исправлено

- Предупреждение о проигнорированном `push.enabled=false` из манифеста теперь попадает в отчёт запуска.

Документация

- README переписан; добавлены справочник команд, описание конвейера, формата патча и конфигурации.
- Указано, какие ключи конфигурации и манифеста код читает, а какие нет.
- Удалён `docs/devctl-universal-v0.3-README.md`: его заменил `docs/pipeline.md`.
- Убраны остатки описания первого проекта, для которого создавался devctl.

## 0.7.0

- Patch Intake: `workspace register`, `inbox init`, `inbox scan`, `inbox grab` доставляют patch.zip из
  общего склада в `patches/` нужного workspace, не применяя его.
- Необязательный раздел `target` в манифесте.

## 0.6.3

- Удаление уже отслеживаемого Python bytecode больше не блокирует коммит; добавление, изменение и
  переименование сгенерированных файлов по-прежнему останавливает `start`.

## 0.6.2

- `init --upgrade`: безопасное обновление существующего workspace без перезаписи путей.

## 0.6.1

- Python bytecode (`__pycache__/`, `*.pyc`, `*.pyo`) из патча не копируется и удаляется из проекта
  после применения и после проверок.

## 0.6.0

- `devctl reset`.
- Автоматический откат проекта после упавших проверок с сохранением снимка `failed_*.zip`.
- `UserTestSpace`: распаковка post-снимка после каждого успешного запуска.

## 0.5.1

- Метаданные установки `install.json`: `self update` знает источник и обновляет completion-файлы.

## 0.5

- Установка как команды пользователя: `self install`, `self update`, `self info`, `self uninstall`.
- Автодополнение для bash, zsh и fish.
- Выбор workspace из любого каталога: `-w` и `DEVCTL_WORKSPACE`.
